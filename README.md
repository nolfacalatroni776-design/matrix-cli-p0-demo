# CLI 接入：首期三个 P0 演示

公开静态交互演示，所有账号、设备、项目和执行结果均为模拟数据，不连接真实平台。

## 支持的三个 P0

1. **浏览器授权登录**：提供固定授权页面，复用网页登录态并保留回调参数，展示设备、账号、权限及有效期，支持同意或拒绝并将结果返回本机 CLI，处理无权限、链接异常及重复提交。
2. **操作确认**：提供固定确认页面，展示操作预览、发起设备与剩余有效时间，支持同意或拒绝并刷新状态，处理账号不匹配、已处理及过期，实际操作由 CLI 执行。
3. **项目 Agent 访问设置**：在现有项目编辑页增加“不开放／只读／全开放”选项，默认不开放，仅项目管理员可修改，并随项目保存。

## 推荐演示流程

浏览器授权登录 → 项目未开放时阻止操作 → 管理员开放项目 → 发起操作并人工确认 → 点击“模拟 CLI 继续”查看模拟执行结果。

顶部“场景预设”可切换异常状态；“重置演示”恢复初始状态。

## 范围

- 首期使用浏览器授权登录，CLI 和浏览器需要运行在同一台电脑。
- 本演示不包含设备码登录及其他 P1 页面。
- 导航、场景预设和模拟终端仅供演示，不代表新增正式产品功能。
- 本项目是前端交互原型，没有真实授权回调、接口请求、数据写入或 CLI 执行。
- `index.html` 包含全部页面脚本、样式和图标，无外部运行时依赖。
